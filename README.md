# One Phrase — 한 문장 외국어

## ▶ 바로 열기: https://sidebatch.github.io/one-phrase/

(옛 주소 https://sidebatch.github.io/une-phrase/ 로 들어와도 새 주소로 자동 이동합니다.)

켜자마자 **미리 만들어진 외국어 한 문장**이 바로 나오는 학습 앱.
고르는 고민도, 직접 만드는 부담도 없이 — 읽고, 따라 쓰고, 가리고 쓰면 한 문장이 끝난다.
콘텐츠는 TEF Canada 준비와 캐나다 일상생활에 바로 쓸 수 있는 문장으로 구성했다.

버전: v1.35.1

## 어떻게 쓰나요

1. **1 · 읽어보기** — 문장, 뜻 덩어리, 핵심 단어를 보고 듣기 버튼으로 소리를 확인한다.
2. **2 · 따라 쓰기** — 문장을 보면서 그대로 타이핑한다.
3. **3 · 가리고 쓰기** — 한국어 뜻만 보고 프랑스어 문장 전체를 쓴다. 악센트가 달라도 정답으로 인정한다.

기본은 **한 문장만**이다. 끝내면 완료 화면이 나오고, 원하면 "한 문장 더"를 누른다.
멈춘 자리에서 자동으로 이어진다. 화면 이동은 헤더의 "☰ 메뉴"로만 하고, 주제별·단어 화면이 보조로 있다.

## 진행 기록 보관

- 저장 키: `une-phrase-progress-v1` (현재 문장 위치, 학습 단계, 완료한 문장, 날짜별 완료 기록, 복습 정답 수(XP), 문장별 완료 날짜, 복습 맞힌 문장 id 목록, 효과음 설정, 언어별 학습 레벨 선택)
- Ensemble 참여 시 같은 완료·복습 기록이 Supabase에도 저장된다 (스키마: `supabase/schema.sql`, 행 단위 보안으로 본인 행만 쓰기 가능). 로그아웃해도 로컬 기록은 그대로 남는다.
- `navigator.storage.persist()`로 영구 보관을 요청하고, 같은 내용을 IndexedDB 보관함(`une-phrase-vault`)에도 복사한다.
- 브라우저가 localStorage를 비우면 보관함에서 복구한다. "기록 전체 지우기"는 보관함까지 함께 지운다.
- 한계: 브라우저에서 사이트 데이터를 전부 삭제하면 보관함도 함께 지워진다. 설명 화면에서 JSON으로 내보낼 수 있다.
- 보관 상태는 앱 안 "더보기" 화면에서 확인할 수 있다.

## 기술

- 단일 파일 `index.html` PWA (홈 화면 설치, 오프라인 동작), 서비스 워커는 네트워크 우선 방식
- Ensemble 백엔드: Supabase (구글 로그인 + Postgres). 클라이언트 라이브러리는 Ensemble 화면을 열 때(또는 구글 로그인에서 돌아온 직후)만 CDN에서 지연 로드하고, 모든 호출은 실패해도 공부 본체에 영향이 없도록 감싸 둔다
- 듣기는 기기 프랑스어 음성(speechSynthesis, fr-FR) 사용 — Android 경합 방지를 위해 취소 후 짧게 기다렸다가 재생한다
- 배포 전 점검: `node tests/run-tests.js` 전부 PASS 후에만 푸시한다 (데이터 정합성, 악센트 허용 채점, 보관함 소실·복구 시뮬레이션, 버전 일치)
